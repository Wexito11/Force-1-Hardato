# Форс-1 - робот-путеобходчик

Проект команды на Всероссийские соревнования по робототехнике «Хардатон «Инженерный вызов» 2026» (МГТУ им. Н.Э. Баумана).

Тема: «Разработка робототехнических систем для автономной инспекции и обслуживания протяжённой критической инфраструктуры». Направление - железная дорога.

## Идея

Автономный робот едет по рельсам и проверяет путь: ширину колеи, перекос, износ головки рельса, стыки и шпалы. Робот состоит из двух модулей - каждый едет по своему рельсу - и двух телескопов между ними. Телескоп одновременно служит измерителем ширины колеи.

Режим укрытия: когда идёт поезд, робот сжимает телескопы, ложится на шпалы между рельсами, пропускает поезд над собой и снимает его ходовую часть снизу. Потом поднимается и возвращается на рельсы.

Обслуживание: маркировка найденных дефектов, уборка металлического мусора электромагнитом, подтяжка ослабших болтов (проба на финале), концепт сварочной головки.

Масштаб прототипа ~1:8: колея 190 мм.

## Структура репозитория

| Папка | Что внутри | Ответственный |
|---|---|---|
| `docs/` | ТЗ и габариты, концепция, план работ, паспорт | вся команда |
| `cad/` | экспорт STEP, рендеры, чертежи деталей | Участник 1 (модули), Участник 2 (телескоп, сборка) |
| `electronics/` | принципиальная схема, распиновка, таблица компонентов .xls | Участник 3 |
| `firmware/esp32_a/` | прошивка модуля A: мотор, полозья, TOF, энкодер | финал |
| `firmware/esp32_b/` | прошивка модуля B: мотор, полозья, телескоп, AS5600, RFID | финал |
| `firmware/rpi/` | Raspberry Pi 5: камера, лидар, IMU, веб-панель оператора | финал |
| `track/` | демо-путь: рельсы, шпалы, дефекты, «вагон» | Участник 4 |
| `edu/` | «Форс-1 Junior» - учебная версия и инструкция для школьников | Участник 4 |

## Правила

- Каждый работает в своей папке.
- Коммит в конце каждого дня с понятным сообщением: что сделано.
- Исходники CAD тяжёлые - храним на общем диске, в git кладём экспорт (STEP, PDF, PNG).
- Перед началом CAD сверяться с `docs/tz-gabarity.md`. Если число меняется - сначала правим этот файл и пишем в чат команды.
