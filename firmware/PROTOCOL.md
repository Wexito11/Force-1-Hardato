# Протокол обмена Raspberry Pi ↔ ESP32 A / B

Текстовые строки, 115200 бод, `\n` в конце. Pi - ведущий, ESP отвечает на команды и шлёт телеметрию 10 раз/с.

ESP A - UART2 Pi (GPIO4/5) или USB, ESP B - UART0 Pi (GPIO14/15) через жгут W1.

## Команды Pi → ESP (общие)

| Команда | Ответ | Что делает |
|---|---|---|
| `PING` | `PONG A` / `PONG B` | проверка связи |
| `M <pwm>` | `OK` | мотор хода, pwm -255…255 (ограничение 80 % внутри) |
| `STOP` | `OK` | мотор 0, всё остановить |
| `SKID UP` / `SKID DN` | `OK` | полозья этого модуля вверх / вниз (плавно) |
| `ENC 0` | `OK` | обнулить энкодер |
| `Q` | строка `T …` | телеметрия по запросу |

## Только ESP A

| Команда | Что делает |
|---|---|
| `CAM <угол>` | MG90S камеры: 0 - вверх (укрытие), 90 - на рельс |
| `MAG DN` / `MAG UP` / `MAG ON` / `MAG OFF` | рычаг и электромагнит |
| `WR DN` / `WR UP` / `WR RUN` / `WR OFF` | гайковёрт: рычаг и мотор; `WR RUN` крутит до остановки по AS5600 №2, отвечает `WR DONE <мс>` или `WR TIMEOUT` |
| `PUMP <мс>` | импульс помпы |
| `TOKEN` | сброс фишки (если помпы нет) |

## Только ESP B

| Команда | Что делает |
|---|---|
| `TEL <шаги>` | телескоп: + сводит, - разводит (шаги NEMA17, 1/16) |
| `TEL FREE` | A4988 отключён - модули разводятся до упора реборд, колея меряется по AS5600 №1 |
| `TEL HOLD` | A4988 включён, держать положение |
| `TEL 0` | обнулить AS5600 №1 в текущем положении (= колея 760) |

## Телеметрия ESP → Pi (10 Гц и по `Q`)

```
T A enc=<имп> tof=<мм> tie=<мм> ...                           (ESP A)
T B enc=<имп> tof=<мм> tie=<мм> gauge=<мм> rfid=<id|->       (ESP B)
```
- `enc` - импульсы энкодера LM393, Pi переводит в мм: `x = enc × π × 50 / N_имп_на_оборот`.
- `tof` - TOF250 до головки рельса, `tie` - HC-SR04 до шпалы (85 мм над шпалой, > 110 - пропуск).
- `gauge` - ширина колеи по AS5600 №1: `760 + Δугол × r_шкива` (знак - в прошивке).
- MPU-9250 читает Pi напрямую по I2C (или ESP A - тогда `roll=<град>` в строке A).

## События ESP → Pi

`EV A LIMIT_WR` (концевик гайковёрта), `EV B RFID <id>`, `EV x ERR <текст>`.
