# Карта проекта «Форс-1»: что есть, где лежит и зачем

Обновлено 09.11.2026. Три места хранения: папка на компьютере `E:\Users\wexle\Documents\Хардатон`, проект «Хардатон» в Claude и репозиторий `github.com/Wexito11/Force-1-Hardato`.

## 1. Одной строкой

Робот-путеобходчик 1:2 (колея 760): два модуля A и B на своих рельсах, соединены телескопом из профилей с ремённым приводом, прячутся между рельсами под поездом. Инспектирует колею, перекос, износ, стыки, шпалы; маркирует дефекты, убирает мусор, подтягивает болт.

## 6. Ключевые числа 1:2 (чтобы не искать)

| Что | Значение |
|---|---|
| Колея / головка / УГР над шпалой | 760 / 37,5 / 100 |
| Шпала / шаг | 1375 (демо ≥ 875) / 272 |
| Зона укрытия | ширина по колёсам поезда |Y| ≤ 345, верх ≤ 117 над шпалой (ГОСТ 9238: 65 мм над УГР / 2 - запас 15) |
| Корпус модуля | 300 × 120 × 66, фанера 4, крышка оргстекло 3 |
| Колесо | обод Ø50 × 40, реборда Ø66, ширина 45, база 240 |
| Телескоп | П 20×20 (A) + прямоугольный 15×10 (B), 2 шт. × 440, ход 80 на модуль |
| Привод телескопа | Г-профиль 632 с ремнём GT2 в A, NEMA17 + шкив Ø15 + ролик в B, AS5600 №1 |
| Полозья | 2 × MG996R на модуль, звенья 60, подошва фанера 6; +50,8° / -42,5° |
| Робот в укрытии | низ 12, корпус 81, лидар 113 над шпалой |
| Масса | ~3,2 кг |
| Питание | VBAT 14,8-16,8 (моторы, A4988, магнит), 6,0 В серво, 5,1 В Pi 5, 5,0 В ESP B |
| Пороги | колея > 8 мм, крен > 0,8°, износ > 8 мм, стык > 12 мм, шпалы 272 ± 40, препятствие < 30 см |

## 8. Открытые вопросы организаторам

Второй ESP32-WROOM, аккумуляторы 18650, помпа и краска, предохранитель 7,5 А, шлейф CSI для Pi 5, JGA 77 об/мин, MX1508 для Junior, RFID-метки (2-4), обратный диод на магнит, входит ли демо-путь в лимиты материалов, магниты к AS5600.
